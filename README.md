O projeto se resume a um petshop, destinado exclusivamente a gatos, contendo produtos e serviços disponiveis para a compra.

Página Inicial: Disponibiliza um menu de navegação para o usuário.
Página de Produtos: Página destinada a apresentação de todas as categorias de produtos e várias opções dentro de cada categoria.
Página de Serviços: Página voltada somente para a navegação entre os serviços disponibilizados pelo petshop.
Rodapé Unificado: Apresente os direitos autorais do projeto, contendo também telefone e email, além do endereço.
